# CloudPulse — Website Uptime & Health Monitor

CloudPulse is a Node.js and Express.js web application that monitors website availability and response time.

## Features
- User registration and login
- Automated website health checks
- UP/DOWN status monitoring
- Response-time tracking
- Downtime and recovery detection
- Email alerts using Nodemailer
- SQLite database for monitoring data

## Tech Stack
Node.js • Express.js • SQLite • Node-Cron • Nodemailer • HTML • CSS • JavaScript
